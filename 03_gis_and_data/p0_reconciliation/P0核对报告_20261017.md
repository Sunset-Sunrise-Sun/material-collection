### 2.3 四个数字的真实关系（数学证明）

被质疑的四个数字 **95 / 116 / 72 / 91 并不矛盾**，因为它们分属**三个不同维度**：

```text
维度A（是否原始已核实）       : 95 条 verified=Y
维度B（本轮判定的精度层级）   : 116（门牌级层）+ 72（仅街道层）+ 30（证据不足）+ 24（冲突）+ 3（无坐标）
维度C（相对上一轮的新增可用） : 91 条（由 123 条原多候选转化而来）

关键关系：
  ① 116 ∩ 95 = 0        → 116 不含任何 verified 记录（断言 C5 已验）
  ② 91 ⊂ (116 ∪ 72)     → 91 全部落在 188 条内，无遗漏（断言 C6 已验）
  ③ 91 = 68 + 23        → 68 条在 116，23 条在 72（断言 C7 已验）
  ④ 188 ∩ 95 = 0        → 188 与 95 互斥（断言 C8 已验）
  ⑤ 95 + 188 = 283      → 有街道归属的全部记录（断言 C9 已验）
  ⑥ 95+116+72+30+24+3 = 340（断言 A3 已验）
```

**逐条解释：**

- **91 不是独立类别，而是 188 的子集。** 它回答的是「上一轮 123 条多候选里有多少条现在可做街道级分析」；
  116 与 72 回答的是「340 条按精度分到哪一层」。两者是**增量视角 vs 存量视角**，不可相加。
- **116 不含 95。** 因此不存在「116 已包含 95、再谈 91 新增就是重复计数」的问题。
- **116 里除 91 的 68 条之外，另有 48 条来自原单候选**（断言 E5）。
- **72 里除 91 的 23 条之外，另有 49 条来自原单候选**（断言 E6）。
- **123 = 91（可用）+ 15（冲突）+ 17（仍需人工）**（断言 D2/D3）。
