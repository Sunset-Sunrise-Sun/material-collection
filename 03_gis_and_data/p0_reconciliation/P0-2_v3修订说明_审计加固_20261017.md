## 一、必修1：脚本继承上一行元数据的缺陷（**确认为真实缺陷，已修复**）

### 1.1 缺陷定性

文件：`03_gis_and_data/phase2_local_gis/reproduce_scripts/01_resolve_coordinates.py`

**原代码结构（缺陷）**：

```python
for r in geo:
    pid = r["place_id"]; addr = r["canonical_address"]
    try:                                    # ← 先做坐标解析
        lng_w, lat_w = float(r["lng_wgs84"]), float(r["lat_wgs84"])
    except (ValueError, TypeError):
        ROWS.append({... "原verified": ver, "原n_candidates": n, "原level": lvl})
        continue                            # ← 此处 ver/n/lvl 尚未赋值

```

