## 归档原则

1. 最新版本与历史版本分开存放，不覆盖原件。
2. 原始输入、整理产物、研究推断、待核问题分层管理。
3. 二进制原件应以原文件形式保存；如另存 Markdown/CSV 提取文本，必须注明是派生版本。
4. 每批上传记录文件名、来源、版本、大小、SHA-256 和校验状态。
5. 不把“检索到摘要”说成“已取得全文”，不把“官方目标”写成“已运营”。
6. 不提交密码、令牌、个人身份信息或其他秘密。

详见 `00_project/ARCHIVE_STATUS.md` 和 `00_project/MATERIAL_MANIFEST.md`，以明确区分已上传内容与待上传原件。
